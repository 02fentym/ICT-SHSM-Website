# ICT SHSM character-select hero

Open `index.html` in a browser. No build step or dependencies are required. HTML, styles, interactions, and artwork are in `index.html`, `styles.css`, `script.js`, and individual PNG files in `assets/`.

Select any of seven student pathways by clicking a portrait. With a portrait focused, use Left/Right arrows to cycle, or Home/End to jump. On phones, swipe the portrait strip. The selected character also highlights its capstone project branch; choosing a branch updates the hero. The Showcase gallery can be filtered by character.

Edit the `characters` array in `script.js` to change names, descriptions, skill tags, and pathway introductions. Each student has a separate full-body PNG and a matching `-headshot.png` image. Update `imageNames` in `script.js` to change the image filenames. Fonts load from Google Fonts with local fallback fonts when offline.

Pathway descriptions are illustrative creative content, not a list of guaranteed courses or certifications. Replace them with your school's specific program details before publishing.

## Program sections

The sections after the hero follow Imagine / Create / Innovate. A sticky section navigation and scroll-progress path connect the journey. Reduced-motion preferences show the full path without animation.

Search `index.html` for `[REPLACE:`, `[XX]`, `[PARTNER LOGO`, `[CERTIFICATION`, and `PLACEHOLDER` to find unfinished program facts, partners, certifications, contact details, and image slots. Capstone cards are illustrative examples. Replace image slots with real images and descriptive alt text. The Learn more disclosures contain placeholders for future dedicated pages; convert their summaries into links when those pages exist. Both Join SHSM links open the supplied Google Form in a new tab.
